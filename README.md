# Django Study

Projeto desenvolvido durante meus estudos de **Django**, acompanhando um curso da Udemy e aplicando os conceitos apresentados durante as aulas.

## 🎯 Objetivo

Praticar o desenvolvimento de aplicações web com Django e compreender, na prática, a estrutura e o funcionamento do framework.

## 📚 Conceitos estudados

Ao longo do projeto serão aplicados conceitos como:

* Estrutura de projetos e aplicações Django
* URLs e rotas
* Views
* Templates
* Models
* Migrations
* Banco de dados
* Administração com Django Admin
* Boas práticas de organização do projeto

## 🛠️ Tecnologias

* Python
* Django
* SQLite
* Git e GitHub

## 🚧 Status

Projeto em desenvolvimento conforme o avanço dos estudos.

> Este repositório possui finalidade educacional e acompanha os exercícios e conceitos apresentados durante o curso.
